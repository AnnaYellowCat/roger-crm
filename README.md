## Описание продукта
CRM-система с клиентским веб-порталом для управления базой отдыха. 
Продукт предназначен для автоматизации процессов бронирования объектов недвижимости (коттеджи, беседки, бассейны), управления финансовыми потоками и администрирования пользователей.

**Ключевые возможности (MVP):**
*   **Для клиентов (Customer):** Интерактивная карта с расположением построек, просмотр занятости, автоматический расчет стоимости, онлайн-бронирование и оплата с внутреннего баланса.
*   **Для администраторов (Admin):** Управление пользователями и ролями, создание и редактирование объектов на карте (Drag-and-Drop), вывод построек из строя с автоматической компенсацией клиентам.
*   **Для менеджеров (Manager):** Управление ценообразованием, создание акций и промокодов, финансовая аналитика.

**Технологический стек (запланирован):** Laravel, Inertia.js, React, TypeScript, SQLite, Docker.
